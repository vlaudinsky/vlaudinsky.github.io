## Project overview
I wanted to make a profile page to show off my skills in a visual way. Sometimes the best way to demonstrate your skills is to put them into the world where it is interactable. When working with clients I have learned that some people need to experience the product in order to understand it.

### Technologies
This portfolio has been made with React and Material UI. The theme has been set for darkmode and light mode with WCAG in mind.
